# Decide one release cadence

[Back to steps](../steps.md)

- **Today:** Collaborate releases weekly, on Wednesday evenings. CDXP ships numbered releases.
- **The problem:** a shared table change has to land before, or together with, either product's code that uses it.
- **Options:**
  - A. A joint calendar. Shared schema changes ship on agreed dates, ahead of either product's release.
  - B. Both teams move to one cadence.
  - C. Independent cadences, with additive-only schema changes so either side can ship first.
- **Lean:** C, plus a joint calendar for any change that isn't additive.
