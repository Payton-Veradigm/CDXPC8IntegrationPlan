# Decide one branching model

[Back to steps](../steps.md)

- **Today:**
  - Collaborate: `main`, plus `release/*` branches.
  - CDXP: `DevBranch`, then `StgBranch`, then `master`.
- **Options:**
  - A. One model for shared code only. Each team keeps its own model for everything else.
  - B. Both teams move to one model.
- **Lean:** A first. Shared code follows its home repo's model, with the other team as required reviewers.
- **Decide with:** [what we share](code-sharing.md) and [the release cadence](release-cadence.md).
